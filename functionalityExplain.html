1 Add Bookmark

নতুন বুকমার্ক তৈরি করে bookmarks array-তে যোগ করে।

📁 জড়িত ফাইলসমূহ

Dashboard.jsx bookmarkActions.js InputFild.jsx TextAreaFilds.jsx TagsInputfilds.jsx PrimaryButton.jsx SecondaryButton.jsx

🔑 State Variables

  • IsFormActive — মডাল দেখানো/লুকানো (boolean)
  • bookmarkData — নতুন বুকমার্কের সব ফিল্ড ধারণ করে (object)
  • bookmarks — পুরো bookmarks array (single source of truth)

⚙️ কিভাবে কাজ করে

  1. Header-এ "+ Add Bookmark" বাটনে ক্লিক → setIsFormActive(true)
  2. Modal form ওপেন হয় — Title, Description, URL, Tags ইনপুট ফিল্ড দেখায়
  3. প্রতিটি ইনপুটের onChange → handleChange(e) → setBookmarkData() আপডেট করে
  4. "Add Bookmark" বাটনে ক্লিক → AddBookmarkFunction(bookmarkData, setBookmarks) কল হয়
  5. ফাংশন: setBookmarks(prev => [...prev, bookmarkData]) — স্প্রেড দিয়ে নতুন এন্ট্রি অ্যাড করে
  6. clearInputFields() কল হয় — সব ফিল্ড রিসেট
  7. মডাল বন্ধ হয়

🔄 Data Flow

Header Button Click → IsFormActive = true → Modal Opens → handleChange() → bookmarkData updates → AddBookmarkFunction() → bookmarks array updated

💻 মূল কোড

// bookmarkActions.js
export function AddBookmarkFunction(bookmarkData, setBookmarks) {
  setBookmarks((prev) => [...prev, bookmarkData]);
}

// Dashboard.jsx — "Add Bookmark" বাটনে onClick

2 Edit Bookmark

বিদ্যমান বুকমার্কের Title, Description, URL, Tags পরিবর্তন করে। ফর্মে আগের ভ্যালুগুলো pre-fill হয়ে আসে।

📁 জড়িত ফাইলসমূহ

Dashboard.jsx BookMarksCard.jsx bookmarkActions.js

🔑 State Variables

  • IsEditFormActive — Edit modal দেখানো/লুকানো
  • editBookmarkData — {id, title, description, url, tags} ধারণ করে

⚙️ কিভাবে কাজ করে

  1. কার্ডের 3-dot মেনু থেকে "Edit" ক্লিক
  2. BookMarksCard → handleEditBookmark(bookmarkObj) কল করে
  3. Dashboard-এ handleEditBookmark() ফাংশন:
    • setEditBookmarkData() দিয়ে পুরানো ভ্যালু সেট করে
    • setIsEditFormActive(true) দিয়ে Edit modal ওপেন করে
  4. Input fields pre-filled থাকে (value={editBookmarkData.title} ইত্যাদি)
  5. ইউজার পরিবর্তন করলে handleEditChange() আপডেট করে
  6. "Save Bookmark" → UpdateBookmarkFunction(editBookmarkData, setBookmarks)
  7. ফাংশন: prev.map() দিয়ে matching ID-র bookmark-এ নতুন ডাটা merge করে

💻 মূল কোড

// Dashboard.jsx
function handleEditBookmark(bookmark) {
  setEditBookmarkData({
    id: bookmark.id,
    title: bookmark.title || "",
    description: bookmark.description || "",
    url: bookmark.url || "",
    tags: Array.isArray(bookmark.tags) ? bookmark.tags : [],
  });
  setIsEditFormActive(true);
}

// bookmarkActions.js
export function UpdateBookmarkFunction(editBookmarkData, setBookmarks) {
  setBookmarks((prev) =>
    prev.map((bookmark) => {
      if (bookmark.id === editBookmarkData.id) {
        return { ...bookmark, ...editBookmarkData };
      }
      return bookmark;
    })
  );
}

4 Pin / Unpin Bookmark

Pinned বুকমার্কগুলো Home page-এ সবসময় ওপরে থাকে। Sort/Filter করলেও pin করা গুলো ওপরেই থাকবে।

📁 জড়িত ফাইলসমূহ

BookMarksCard.jsx bookmarkActions.js Home.jsx

🔑 State Property

প্রতিটি bookmark object-এ isPinned: true/false

⚙️ কিভাবে কাজ করে

  1. Active কার্ডের মেনুতে "Pin" বা "Unpin" ক্লিক
  2. pinbookmarksfunction(id, bookmarks, setBookmarks) কল হয়
  3. ফাংশন: bookmark.isPinned toggle করে (!bookmark.isPinned)
  4. Home.jsx-এ rendering:
    • pinnedBookmarks = isPinned === true গুলো আলাদা
    • unpinnedBookmarks = বাকিগুলো sort হয়
    • displayBookmarks = [...pinnedBookmarks, ...sortedUnpinnedBookmarks]
  5. কার্ডের নিচে 📌 আইকন দেখায় (isPinned হলে)
  6. ⚠️ Archived কার্ডে Pin অপশন hidden থাকে

💻 মূল কোড

// bookmarkActions.js
export function pinbookmarksfunction(key, bookmarks, setBookmarks) {
  const updatedBookmarks = bookmarks.map((bookmark) => {
    if (bookmark.id === key) {
      return { ...bookmark, isPinned: !bookmark.isPinned };
    }
    return bookmark;
  });
  setBookmarks(updatedBookmarks);
}

// Home.jsx — Pin-first ordering
const displayBookmarks = [...pinnedBookmarks, ...sortedUnpinnedBookmarks];

5 Archive / Unarchive Bookmark

Archive করলে বুকমার্ক Home থেকে সরে Archived ট্যাবে যায়। Unarchive করলে আবার Home-এ ফিরে আসে।

📁 জড়িত ফাইলসমূহ

BookMarksCard.jsx bookmarkActions.js Home.jsx ArchivedBookmarks.jsx

🔑 State Property

প্রতিটি bookmark object-এ isArchived: true/false

⚙️ কিভাবে কাজ করে

  1. Active কার্ডে "Archive" ক্লিক → isArchived = true
  2. Archived কার্ডে "Unarchive" ক্লিক → isArchived = false
  3. Home.jsx: bookmarks.filter(b => !b.isArchived) — শুধু active গুলো দেখায়
  4. ArchivedBookmarks.jsx: bookmarks.filter(b => b.isArchived) — শুধু archived গুলো দেখায়

💻 মূল কোড

export function Archivedbookmarksfunction(key, bookmarks, setBookmarks) {
  const updatedBookmarks = bookmarks.map((bookmark) => {
    if (bookmark.id === key) {
      return { ...bookmark, isArchived: !bookmark.isArchived };
    }
    return bookmark;
  });
  setBookmarks(updatedBookmarks);
}

6 Visit Bookmark (URL Open)

বুকমার্কের URL নতুন ট্যাবে খোলে এবং view count ও last visited date আপডেট করে।

📁 জড়িত ফাইলসমূহ

BookMarksCard.jsx bookmarkActions.js

⚙️ কিভাবে কাজ করে

  1. কার্ডের মেনু থেকে "Visit" ক্লিক
  2. VisitBookmarkUrl(id, bookmarks, setBookmarks) কল হয়
  3. ফাংশন:
    • views += 1 — ভিজিট কাউন্ট বাড়ায়
    • cardLVDate — আজকের তারিখ সেট করে
    • URL-এ http না থাকলে https:// যোগ করে
    • window.open(url, "_blank") — নতুন ট্যাবে খোলে

💻 মূল কোড

export function VisitBookmarkUrl(key, bookmarks, setBookmarks) {
  for (let i = 0; i < bookmarks.length; i++) {
    if (bookmarks[i].id === key) {
      let viewupdate = (bookmarks[i].views += 1);
      setBookmarks((prev) => {
        const updatedBookmarks = prev.map((bookmark) => {
          if (bookmark.id === key) {
            return {
              ...bookmark,
              views: viewupdate,
              cardLVDate: new Date().toLocaleDateString("en-GB", {
                day: "2-digit", month: "short", year: "numeric",
              }),
            };
          }
          return bookmark;
        });
        return updatedBookmarks;
      });
      const url = bookmarks[i].url.startsWith("http")
        ? bookmarks[i].url : `https://${bookmarks[i].url}`;
      window.open(url, "_blank");
      return;
    }
  }
}

7 Copy URL

বুকমার্কের URL ক্লিপবোর্ডে কপি করে।

📁 জড়িত ফাইলসমূহ

BookMarksCard.jsx bookmarkActions.js

⚙️ কিভাবে কাজ করে

  1. কার্ডের মেনু থেকে "Copy URL" ক্লিক
  2. CopyBookmarkUrl(id, bookmarks) কল হয়
  3. ID দিয়ে bookmark খুঁজে URL বের করে
  4. navigator.clipboard.writeText(url) — ক্লিপবোর্ডে কপি

💻 মূল কোড

export function CopyBookmarkUrl(key, bookmarks) {
  const bookmark = bookmarks.find((item) => item.id === key);
  if (!bookmark) return;
  const url = bookmark.url.startsWith("http")
    ? bookmark.url : `https://${bookmark.url}`;
  navigator.clipboard.writeText(url);
}

9 Sort By (Filter Dropdown)

৩টি সর্টিং অপশন আছে। Pinned bookmarks সর্ট থেকে exempt — সবসময় ওপরে থাকে।

📁 জড়িত ফাইলসমূহ

Home.jsx ArchivedBookmarks.jsx

🔑 State

sortBy — Home ও Archived-এ local state (default: "Recent added")

⚙️ ৩টি Sort অপশন

  • Recent added — ID অনুযায়ী নতুন থেকে পুরানো (b.id - a.id)
  • Recently visited — Last visited date অনুযায়ী (cardLVDate)
  • Most visited — সবচেয়ে বেশি ভিজিট করা (b.views - a.views)

⚙️ Pin Exemption Logic

// Home.jsx
const pinnedBookmarks = activeBookmarks.filter((b) => b.isPinned);
const unpinnedBookmarks = activeBookmarks.filter((b) => !b.isPinned);

// শুধু unpinned গুলো sort হয়
const sortedUnpinnedBookmarks = [...unpinnedBookmarks].sort((a, b) => {
  if (sortBy === "Recent added") return (b.id || 0) - (a.id || 0);
  if (sortBy === "Recently visited") { /* date comparison */ }
  if (sortBy === "Most visited") return (b.views || 0) - (a.views || 0);
});

// Pinned আগে, তারপর sorted unpinned
const displayBookmarks = [...pinnedBookmarks, ...sortedUnpinnedBookmarks];

10 Filter by Tags (Sidebar Checkboxes)

Left sidebar-এ ট্যাগ চেকবাক্সে ক্লিক করলে সেই ট্যাগ যুক্ত বুকমার্কগুলো ফিল্টার হয়ে দেখায়। একাধিক ট্যাগ সিলেক্ট করা যায়।

🔑 State

🔄 Data Flow

⚙️ কিভাবে কাজ করে

  1. চেকবাক্স ক্লিক → handleTagToggle("JavaScript")
  2. আগে থেকে selected থাকলে remove করে, না থাকলে add করে
  3. Home.jsx / ArchivedBookmarks.jsx-এ matchesSelectedTags() ফাংশন:
    • selectedTags খালি হলে সব দেখায়
    • না হলে bookmark.tags-এ কোনো একটি selected tag match করলে দেখায়
  4. Pinned bookmarks-ও ফিল্টার হয় — match করলে ওপরে দেখায়, না করলে লুকায়

💻 মূল কোড

// Dashboard.jsx
function handleTagToggle(tagName) {
  setSelectedTags((prev) =>
    prev.includes(tagName)
      ? prev.filter((t) => t.toLowerCase() !== tagName.toLowerCase())
      : [...prev, tagName]
  );
}

// Home.jsx
const matchesSelectedTags = (b) => {
  if (!selectedTags || selectedTags.length === 0) return true;
  return b.tags?.some((tag) =>
    selectedTags.some((s) => s.toLowerCase() === tag.toLowerCase())
  );
};

// leftSidebar.jsx — checkbox
<input
  type="checkbox"
  checked={selectedTags.some(t => t.toLowerCase() === item.name.toLowerCase())}
  onChange={() => handleTagToggle(item.name)}
/>

12 Dark Mode / Light Mode

Theme toggle করলে পুরো অ্যাপের রঙ পাল্টায়। LocalStorage-তে সেভ হয় — রিলোড করলেও theme ধরে রাখে।

📁 জড়িত ফাইলসমূহ

App.jsx Header.jsx index.css

🔑 State

darkMode — App.jsx-এ boolean state, localStorage থেকে initialize হয়

⚙️ কিভাবে কাজ করে

  1. App.jsx-এ darkMode state — localStorage.getItem("theme") থেকে পড়ে
  2. useEffect-এ document.documentElement.classList.add/remove("dark")
  3. Header-এ ☀️ (Light) ও 🌙 (Dark) বাটন — ক্লিক করলে setDarkMode(!darkMode)
  4. index.css-এ @custom-variant dark (&:where(.dark, .dark *)) — Tailwind v4 dark mode
  5. সব কম্পোনেন্টে dark: prefix দিয়ে dark variant styling আছে

💻 মূল কোড

// App.jsx
const [darkMode, setDarkMode] = useState(() => {
  return localStorage.getItem("theme") === "dark";
});

useEffect(() => {
  const root = document.documentElement;
  if (darkMode) {
    root.classList.add("dark");
    localStorage.setItem("theme", "dark");
  } else {
    root.classList.remove("dark");
    localStorage.setItem("theme", "light");
  }
}, [darkMode]);
